## Bugs Found

### BUG #1: React Hydration Error After Login (HIGH)

**Severity:** High
**Location:** `apps/server/src/app/[locale]/auth/login/page.tsx:38`

**Description:**
After successful login, `router.push('/dashboard')` redirects to `/dashboard` without the locale prefix, causing a React hydration error:
```
NotFoundError: Failed to execute 'removeChild' on 'Node':
The node to be removed is not a child of this node.
```

**Expected:** Redirect to `/en/dashboard` or `/ar/dashboard`
**Actual:** Redirects to `/dashboard` causing hydration mismatch

**Recommended Fix:**
```typescript
// In login/page.tsx, change:
router.push('/dashboard');

// To:
import { usePathname } from 'next/navigation';
const locale = pathname.split('/')[1] || 'en';
router.push(`/${locale}/dashboard`);

// Or use next-intl's router:
import { useRouter } from '@/i18n/routing';
router.push('/dashboard'); // This should handle locale automatically
```

---

### BUG #2: Logout Redirects to Wrong Port (MEDIUM)

**Severity:** Medium (Dev environment only)
**Location:** `apps/server/src/components/layout/Header.tsx:44`

**Description:**
When logging out, the `signOut({ callbackUrl: '/' })` redirects to `http://localhost:3000/` instead of the current server port (3003). This is because `NEXTAUTH_URL` is likely set to port 3000.

**Expected:** Redirect to same port as current session
**Actual:** Redirects to hardcoded port from NEXTAUTH_URL

**Recommended Fix:**
```typescript
// Option 1: Use relative URL
await signOut({ callbackUrl: '/' });

// Option 2: Use window.location.origin
await signOut({ callbackUrl: window.location.origin });
```

Also update `.env`:
```
NEXTAUTH_URL=http://localhost:3003
```
